🎮 Among Us Headquater

Ein leistungsstarkes Tool-Set zur Steuerung von Multi-Twitch-Streams auf einem oder zwei Monitoren – optimiert für Among Us Runden und Multi-POV Watching.
🚀 Hauptfunktionen

    1-Screen & 2-Screen Modus: Flexible Aufteilung der Streams auf einen oder zwei Monitore.

    Smartphone Remote Control: Steuerung direkt per QR-Code vom Handy aus (inklusive stabilem Auto-Reconnect).

    Favoriten & Imposter Modi: Automatische Zuweisung (Screen 1 zeigt Favoriten und Imposter, Screen 2 die restlichen aktiven Spieler).

    Latenz-Synchronisierung: Alle Stream-Latenzen mit einem Klick angleichen.

🛠️ Installation
1. Web-Player & Remote (GitHub Pages)

    Player: Among Us Headquater Player

    Remote: Among Us Headquater Remote

2. Browser-Erweiterung

    Firefox: Direkt im offiziellen Firefox Add-ons Store verfügbar.

    Google Chrome: Lade die fertige .zip-Datei direkt aus diesem GitHub-Repository herunter, entpacke sie auf deinem PC und füge den Ordner in Chrome über chrome://extensions/ (Entwicklermodus -> "Entpackte Erweiterung laden") hinzu.

📖 Bedienung

    Streams auswählen: Öffne das Popup der Erweiterung und wähle die aktiven Streamer aus.

    Fenster öffnen: Klicke auf Fenster 1 (und ggf. Fenster 2 für den Dual-Screen-Modus).

    Handy verbinden: Scanne den QR-Code im Popup mit deiner Smartphone-Kamera.

    Live steuern: Vergebe während des Spiels unkompliziert die Rollen ⭐ (Favorit) oder ⚔️ (Imposter).

⚙️ Technischer Stack

    Frontend: HTML5, CSS3, JavaScript (ES6+)

    P2P Kommunikation: PeerJS (WebRTC mit Heartbeat)

    Extension API: WebExtensions API (Manifest V3)
